# Simulator results

20 runs per point; 1 km² area, random-waypoint walking (0.5–1.5 m/s, pauses up to 60 s), 30 min per run,
20 SOS from random phones in minutes 1–10, 5% of phones are gateways. Delivered = a gateway holds the SOS.
Plain flooding is the same relay code with store-carry-forward off. Generated by `./gradlew :simulator:run`.
